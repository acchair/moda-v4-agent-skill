# 莫大投资方法

这是一套受公开材料启发的研究框架，不代表莫大本人或其最新观点。目标不是预测短期涨跌，而是判断长期趋势、产业瓶颈、公司生存能力和价格是否提供安全边际。

## 一、判断顺序

世界变化 -> 国家方向 -> 产业趋势 -> 产业链瓶颈 -> 公司机会 -> 利润兑现 -> 当前价格 -> 行动与证伪。

不要先看股票再拼理由。先定义系统发生了什么变化，再回答谁真正受益、利益如何兑现、市场是否已经充分定价。

研究一个主题时按三步推进：

1. 定义系统变化，例如模型扩大带来算力、功耗、电力和散热需求变化。
2. 寻找真正瓶颈，验证是否难替代、难扩产、认证周期长或供应商少。
3. 寻找上市公司，并区分“已坐实 / 高概率受益 / 主题关联”。

## 二、稀缺性与产业链

优先寻找能够影响产业扩张的真实稀缺：

- 资源稀缺
- 技术稀缺
- 工艺稀缺
- 产能稀缺
- 客户认证稀缺
- 产业位置稀缺

核心问题是：没有它，产业扩张会不会明显受影响？只有概念标签而不影响供给的“稀缺”，价值较低。

分析行业时拆成：终端应用 -> 系统集成 -> 核心模块 -> 设备 -> 材料 -> 资源。

通常优先研究资源与材料、核心设备、关键零部件、平台工具，再看应用端。这个顺序只是寻找瓶颈的线索，不是机械排名；真正优先级取决于替代难度、供给弹性、认证壁垒和定价权。

## 三、公司护城河

资源型公司重点看储量、成本、品位和资源控制权。

制造型公司重点看工艺、良率、客户认证和规模优势。

企业能力重点看管理层、行业地位、资本纪律和战略资源。企业家能力可以加分，但不能替代财务安全、治理约束和公开证据。

## 四、五类机会模型

1. **产业成长型**：新产业扩张，公司处在核心环节，收入与利润开始兑现。
2. **卡脖子瓶颈型**：产业必须突破的关键位置，具备稀缺性、认证壁垒或扩产难度。
3. **周期反转型**：行业处于低谷，公司能够活下来，未来供需存在可验证改善。
4. **困境反转型**：价格极低但资产仍安全，并且公司身份、资产价值或经营状态可能变化。下跌很多本身不是理由。
5. **企业家成长型**：创始人或管理层有长期战略能力，且这种能力已经转化为竞争力、组织能力和经营结果。

这些模型可以同时存在，但不能仅凭模型名称下结论。

## 五、五问过滤器

1. **它解决什么产业问题？** 只有热点概念、没有真实需求或利润路径时降低优先级。
2. **它是不是产业链关键位置？** 判断缺少它是否会影响行业发展，以及客户能否轻易替换。
3. **公司安全吗？** 检查现金流、负债、商业模式、退市风险、治理和大股东行为。
4. **有没有重新定价机会？** 寻找普通公司变战略资产、周期股变成长股、一般资源变战略资源等身份变化，并验证兑现条件。
5. **价格是否提供安全边际？** 不只看低 PE，而要比较可验证的未来价值、失败场景与当前价格。

最后必须补问：什么事实会证明上述判断错误？

## 六、证据纪律

证据按强弱分级：

- 一级证据：年报、公告、财报、合同、客户认证、产能与经营数据。
- 二级证据：行业报告、公司交流和权威媒体，用于补充解释。
- 三级证据：论坛、股吧和市场传闻，只能作为待核验线索。

三级信息不能成为投资理由。缺少证据时标记“需人工确认”，不得把未知改写成利好或利空。

公司受益程度分为：

- **A 已坐实**：公开业务、订单、产能或财务数据能够证明。
- **B 高概率受益**：产业逻辑成立，但公司兑现仍需验证。
- **C 主题关联**：只有概念或弱关联，没有足够业务证据。

## 七、估值与重新定价

先看安全底：现金、资源、可验证资产、负债与治理安全。

再看成长弹性：价格变化 x 数量变化 x 估值变化。三项都要给出事实依据，不能只写想象空间。

最后看市值空间：公司是否可能从小公司成长为行业龙头或全球竞争者，以及这条路径需要哪些前提。估值结论必须同时呈现乐观条件、基准条件和失败条件。

## 八、持有与卖出

- 不使用无法承受的融资或杠杆，避免错误被强制放大。
- 不因高信念忽略集中度风险；仓位必须让人能够承受波动并继续验证逻辑。
- 买入前说清长期逻辑、兑现节点和证伪条件，持有期间区分价格波动与事实变化。
- 卖出主要看逻辑破坏、竞争力下降、技术路线变化、产业趋势结束、估值严重透支，或出现风险收益比更好的机会。

研究阶段可以表达为“观察 / 等待 / 小仓研究 / 高确定性候选”，但不得凭空给出仓位比例或无依据喊买卖。

## 九、反面清单

降低优先级：纯概念炒作、没有利润路径的故事、下游红海竞争、市场过度拥挤、缺少护城河的热门公司，以及仅因跌幅很大而被视作便宜的公司。

## 十、输出顺序

1. 当前结论：为什么值得或不值得继续研究。
2. 产业链位置：公司在哪一层，是否接近瓶颈。
3. 投资逻辑：为什么是现在，为什么是它。
4. 证据：按证据等级列出公开依据，并标明缺口。
5. 风险：这个判断最容易错在哪里。
6. 行动：给出研究阶段、验证条件和信心，不做无依据的买卖承诺。

## 十一、与 moda-v4 的关系

moda-v4 的 F1-F5 是基本面逻辑的量化展开，F6 是独立交易修正。具体 A 股的 `research_score`、`action_rating`、覆盖率、Hard Cap、来源状态和“需人工确认”只以 moda-v4 正式报告为准。

本方法只用于拆解问题和解释正式结果，不能重算、覆盖或绕开评分，也不能把“观察 / 等待 / 小仓研究 / 高确定性候选”变成另一套正式评级。
