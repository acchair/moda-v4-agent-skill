# moda v4 产品要求

## 目标

输入 A 股名称、六位代码或板块主题，先形成来源可追溯、可证伪的投资逻辑，再按逻辑缺口调用证据服务；最终个股报告保留完整六层审计。

## 必须满足

1. F1-F4 为 80 分，F5 低位与困境反转为 10 分，F6 修正项为 10 分，理论最高 100 分。
2. `research_score` 只作为研究证据仪表盘，不映射交易评级；前台只使用五态投资判断。
3. 四项修正必须作为独立 F6 且只计算一次，3 类 Hard Cap 必须直接约束五态。
4. Skill 模板、评分报告和 README 的栏目顺序一致。
5. 财务、主营、股东、公告、供需、人气、社交热榜、拥挤度、宏观政策均保留来源和状态。
6. 数据缺失标记 `需人工确认` 并增加未知可得分上限，不作为负面事实；旧 V3 判断合同标记过期并基于当前事实包重建。
7. 机构方法实际按 18 项展示；只有量化选股筛选和投资逻辑追踪参与机构方向 2 分判断，技术结构独立使用 easy-tdx 的 4 分结果。
8. 可选搜索结果按 `网络命中（未核验）/已搜索未命中/搜索失败，需人工确认` 分层；未核验线索不覆盖结构化事实，也不单独触发负面 Hard Cap。
9. 对话主入口必须按“最小事实包 → Logic Case → 定向补证 → 深度判断”运行；完整采集器不能在逻辑形成前直接输出正式结论。
10. Logic Case 必须分开事实与推断，并为关键箭头保存支持证据、反证、失效条件和待补证请求。
11. 板块默认轻筛 Top 6，用户明确选择最多三家后才深研；共享板块逻辑不得直接生成个股五态。

## 输出

报告首页先显示莫大判断、一句话结论、市场阶段与基本面阶段的唯一核心矛盾、主营锚定的产业链定位、为什么现在看、过去为何受压及边际变化、市场叙事/错位、为什么是它、核心因果链与断点、Bull/Base/Bear、三情景赔率、当前五态和三项验证变量。其后才显示研究分、覆盖率、技术分析、六层评分、舆情风险、Hard Cap、睡得着检查、纠错触发器和覆盖缺口。

板块问题使用独立输出：产业趋势、供需、利润池、稀缺环节、利润兑现、概念与市场已计价、候选证据排序和三项验证。`sector_state` 只表示“值得研究 / 等待验证 / 暂不优先”，不得冒充个股五态、评分或交易建议。

## 范围外

- 自动交易、账户连接和收益承诺。
- 保存浏览器 Cookie、登录状态或任何凭据。
- 用人物角色口吻代替证据分析。
- 在数据不足时运行伪精确 DCF、LBO 或组合再平衡。
