# 数据源与方法评估

> 需要按选股问题查找可用接口、真实上游、降级链、字段和证据边界时，请使用 [数据源接口目录](DATA_SOURCES.md)。

## 已验证数据链

| 数据 | 当前来源 | 处理规则 |
|---|---|---|
| 行情/K线/技术 | 当日持久缓存 → easy_tdx/TDX → BaoStock → AKShare/东财 → AKShare/Sina → Tencent | 缓存记录来源状态；校验 OHLC、日期、重复行和新鲜度；三年分位至少需要 720 根有效日 K；BaoStock 是 B 级独立传输通道，腾讯只作末级备用 |
| 财务 | easy_tdx/Sina → AKShare/Sina → AKShare/同花顺；BaoStock 摘要独立校验 | 完整三表最多取 20 期并提取 FCF、净债务、净现金率、短债覆盖、负债率和同比趋势；BaoStock 仅按相同报告期校验净利润、负债率、现金流质量，并对缺失指标作 B 级末级部分补缺 |
| 历史估值/股本 | EastMoney 估值分析 → 百度估值 | 东财序列同时提供五年 PE/PB、总股本、流通股本和市值；百度只补 PE/PB |
| 主营/海外收入 | EastMoney F10 | 仅在存在有效地区披露时生成海外收入比例 |
| 公告 | easy_tdx/CNINFO | 180 日分页到日期边界或末页；覆盖不完整不反推安全 |
| 专精特新/行业龙头/核心供应商 | `tools/scoring/专精特新_行业龙头_核心供应商_A股名单_完整版.csv` | 按证券代码优先、证券简称兜底；命中直接记录名单来源，未命中分类才进入权威网络核验 |
| 股东/质押/解禁 | Sina + EastMoney + 沪深港通 | 记录逐接口状态；失败或比例字段缺失不记为 0；北向变化只在基金变化缺失时补充 F2 |
| 个股人气 | EastMoney stockrank | 排名归一化为 0-1 热度 |
| 市场拥挤 | 乐咕乐股/申万二级行业拥挤度 → 申万指数成交活跃度代理 | 先映射申万二级行业；全量行业表每日共享；主源过期/失败时才使用成交额与成交量滚动分位代理，并明确标记口径 |
| 行业财务景气 | 乐咕申万行业中位数 | B 级聚合数据；当期、上期和边际变化，只作交叉验证 |
| 行业趋势/资金 | 申万指数 + AKShare | 相对强度、成交活跃和资金流，只验证市场定价 |
| 社交热榜/个股讨论 | 6 个平台公开接口 + 雪球/东方财富公开接口 + DuckDuckGo Lite/带引用模型搜索 | 热榜 5 分钟缓存；记录 7 天快照、去重主题、排名跃升和传播速度；讨论直接接口优先，少于样本门槛必须标记样本不足 |
| 新闻舆情 | 金十快讯 + 东方财富快讯 + 同花顺快讯 | 10 分钟缓存；只作事件与舆情补充，不并入社交热度，不替代 CNINFO 公告 |
| 商品供需 | AKShare | 现货、基差、库存至少两类同向 |
| 宏观政策 | LPR、PMI、PPI、gov.cn JSON | 只作背景，不因单条标题加分 |
| 海外增量雷达 | 按行业从 FDA/ClinicalTrials、SEC、EIA、DoD、USDA、Fed 等监管一手层，及 Reuters、行业专业站点中各选 4 个 | 先识别 III 期/审批/并购授权/订单/资本开支等增量，再映射为待核验产业链；不以海外股价或概念标签推导 A 股受益 |
| 搜索补缺 | DuckDuckGo Lite → DeepSeek Web Search → OpenAI Web Search → 带引用模型网关 | 默认首轮覆盖全部 F1-F5 缺口；按公司、产业、产业链、利润、市场预期选择来源。模型联网工具由代码显式请求；没有真实 URL、可读正文或对象匹配的结果直接丢弃，命中仍只形成未核验线索 |

## hot-money 评估

可借鉴：多平台独立降级、热榜短缓存、陷阱信号单列、机构方法的数据门槛和最终自查。

不直接采用：人物角色评分、搜索摘要关键词直接定性、未搜到即安全、用默认值补齐 DCF/LBO、虚构示例持仓。

其机构方法文档存在 15/17/18 三种数量口径，当前索引实际列出 18 项。v4 不复制其第二套评分，而是逐项展示适用状态；只有量化筛选和投资逻辑追踪能在双重反向时降低 Alpha 1 分。

## 当前限制

- 微博和抖音公开接口可能拒绝请求，报告会显示平台失败。
- 社交热榜只能证明热点可见性，不能覆盖私域群或完整社区讨论。
- 首次运行只有一个热榜快照，传播速度和排名跃升需要后续快照才能计算；相同新闻转载会先去重再统计平台传播。
- 个股讨论少于 10 条、只有一个结构化来源或来源失败时，情绪结论会降为有限/样本不足，不把少量帖子当成市场共识。
- 政府网最新政策页只适合近期标题匹配，不等于完整行业政策库。
- DCF 和三表需要更完整的自由现金流、股本、净债务和经营假设，当前默认不运行。
- DuckDuckGo Lite 可能返回反爬页；模型搜索需要用户自行配置 API/桥接端点。DeepSeek 和 OpenAI 的联网工具都必须返回真实引用 URL；普通 Chat API 不等于联网搜索。
- 乐咕财务景气目前以申万一级行业中位数为主；二级行业依靠指数和公司侧数据补充，不能伪装成完整二级行业财务验证。
- 产业渗透率、CR3、扩产周期、行业产能利用率和资本开支缺少统一的全行业结构化接口；搜索结果必须先通过来源类型、正文可读性和对象匹配核验，才可作为未核验线索并保留 URL 与查询词。公司公告催化需要有日期和明确事件细节，单个标题词不直接计分。
- 板块/概念的海外扫描只分出情绪、产业、订单、利润四类催化；“订单/利润”只代表优先核对 A 股 F10 收入暴露、订单与利润表，不能跳过同业比较、估值和失效条件，更不能直接生成五态结论。
- 雪球景气文章用于确定“财务确认 + 供需先行”的方法结构，不作为任何股票或行业的评分证据。

## 数据源健康检查

```powershell
python tools/source_health.py --group all
python tools/source_health.py --group social --json
```

健康检查覆盖 easy-tdx、BaoStock、AKShare、efinance、腾讯行情/K线、6 平台热榜和 3 个财经快讯源。检查结果只用于诊断连通性，不改变评分，也不会把失败来源当成负面证据。
